# Customer Migration Batch

Mini-proyecto de preparación para entrevista técnica Senior Java.

## Stack

- Java 21
- Spring Boot
- Spring Batch
- Spring Data JPA
- PostgreSQL
- JUnit 5
- Mockito
- Maven

## Objetivo

Migrar clientes desde un modelo legacy hacia un modelo objetivo utilizando Spring Batch, procesamiento por chunks, validación, transformación, manejo de errores, transacciones, restartability e idempotencia.

## Branch principal de desarrollo

`feature/initial-setup`

## Configuración local

Definir las variables de entorno:

- `DB_URL`
- `DB_USERNAME`
- `DB_PASSWORD`

No almacenar credenciales de PostgreSQL en el repositorio.
